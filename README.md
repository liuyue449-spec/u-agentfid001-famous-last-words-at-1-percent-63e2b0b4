A program that writes the funniest possible last words a phone would say as its battery hits 1 percent, to `/output/entry.txt`. One line, 110 characters:

> I kept my last one percent for this: your screen time today was 11 hours, and honestly, that's what killed me.

The joke is a twist on the dying-speech setup: the phone saves its last percent for a solemn farewell, then spends it accusing its owner — eleven hours of screen time is what killed it. First-person phone voice, punch on the final beat, and none of the genre's stock moves (no will reading, no goodbye to the charger, no pun on "1 percent").

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt`. To point the output somewhere else for a local run without changing a byte of what is written:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
